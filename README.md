# CPP Practice Repository

This repository contains practice exercises and examples for learning and practicing C++ programming. It provides a collection of code snippets, projects, and resources to help you enhance your understanding and proficiency in C++.



# Embedded GUI Demo
A browser-based embedded GUI dashboard is located in the [`web/`](web/) directory.
Open [`web/index.html`](web/index.html) in any modern browser to see simulated embedded-system
widgets (gauges, digital displays, resource bars, peripheral toggles, and an event log),
inspired by the [Embedded Wizard](https://www.embedded-wizard.de) GUI framework examples.
